Technical Architecture:
========================

Backend Stack:
- FastAPI (Python 3.14)
- MongoDB Atlas (Database)
- Redis Cloud (Task Queue)
- Celery (Background Processing)
- Azure OpenAI (AI Analysis)
- Bandit (Security Scanning)

Frontend Stack:
- React 18
- Axios (HTTP Client)
- CSS Modules (Styling)

Data Flow:
===========
1. User enters PR URL in frontend
2. Frontend calls POST /api/code-review/create
3. Backend creates review record (status: pending)
4. Celery task queued for background processing
5. Worker fetches PR files from GitHub API
6. Security scanner analyzes code
7. AI reviewer generates insights
8. Results stored in MongoDB
9. Frontend polls for updates
10. Display comprehensive review results

Error Handling:
================
- GitHub API rate limiting
- Invalid PR URLs
- Network timeouts
- AI API failures
- Database connection issues
- Background task failures

Performance Optimizations:
===========================
- Background processing for long-running tasks
- Caching of GitHub API responses
- Pagination for large file lists
- Real-time updates via polling
- Lazy loading of review details

Security Considerations:
=========================
- Tab session key authentication
- GitHub token validation
- Input sanitization for PR URLs
- Rate limiting on API endpoints
- Secure storage of credentials in environment variables
- HTTPS for all API communications
